# DevzON native game data

Public, verified resource files for the original in-game downloader. An unofficial fan project; game systems are still under development.

Two versioned releases hold 1,980 binary files (3,822,184,572 bytes). The manifest and publication plan include MD5 and SHA256 checksums. No player saves, authentication credentials, or backend configuration are published.

GitHub Releases provide free binary storage and delivery. Files are mapped from their original game paths by the VPS; it redirects downloads without relaying their content. No Git LFS, paid object storage or Actions artifacts are used.
